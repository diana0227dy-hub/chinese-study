# Chinese Study

중국어 플래시카드, 자주 틀리는 표현, 일기, 학습 기록 및 대시보드를 위한 정적 웹사이트 MVP.

## GitHub Pages 배포
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

## 제한
데이터는 각 브라우저의 localStorage에 저장됩니다. JSON 백업/복원을 지원합니다. ChatGPT 프로젝트 대화 자동 수집과 AI 교정은 아직 구현되지 않았습니다. 공개 저장소에 개인 일기 및 대화 원문을 업로드하지 마세요.
