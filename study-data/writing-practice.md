# 중국어 작문 및 교정 기록

> 실제 학습 대화에서 확인된 문장들. 연습 문제는 실제 개인 생활 사실을 의미하지 않습니다.

## 최근 5문장 작문 (2026-10 말)

1. **신발**
   - 작성: 我因为这双鞋很漂亮，穿起来不太舒服。
   - 교정: 我觉得这双鞋很漂亮，但是穿起来不太舒服。
   - 핵심: 因为(이유)와 以为(예상), 觉得(생각하다) 구분. 穿起来 사용은 적절.
2. **출근/지각**
   - 작성: 我平时坐？上班，不过今天路上很多车，所以我到晚了。
   - 교정: 我平时坐地铁上班，不过今天因为堵车迟到了。
   - 핵심: 坐地铁, 堵车, 迟到. 지하철 출근과 도로 정체의 인과관계는 실제 상황에 따라 조정 필요.
3. **식당**
   - 작성: 我以为这家餐厅很贵，没想到更便宜和菜也很好吃。
   - 교정: 我以为这家餐厅很贵，没想到比想象中便宜，而且菜也很好吃。
   - 핵심: 比想象中(更)便宜, 而且. 以为…没想到…는 정확하게 사용.
4. **운동할 시간**
   - 작성: 我最近太忙了，没有就运动时间。
   - 교정: 我最近太忙了，连运动的时间都没有。
   - 핵심: 连…都没有, 运动的时间.
5. **피곤해도 공부**
   - 출제: 아무리 피곤해도 나는 매일 중국어를 공부하려고 해.
   - 답변 기록: 이 문제에 대한 작문 답변은 확인되지 않음.

## 앞선 5문장 작문

1. 평소 옷차림: 我平时喜欢穿T恤和牛仔裤。 (정답)
2. 교통/생활: 작성 我家附近的交通环境方便，所以生活很好。 → 교정 我家附近交通很方便，所以住在这里很舒服。
3. 음식 취향: 我喜欢各种各样的菜，尤其喜欢中国菜。 (정답)
4. 직무: 작성 我在半道？公司研发工作。 → 교정 我在半导体公司从事研发工作。
5. 만족/피곤: 작성 我对现在的工作满意，不过有时候太累了。 → 더 자연스럽게 我对现在的工作很满意，不过有时候太累了。

## 추가 학습한 예문
- 我以为这双鞋很漂亮，没想到穿起来不太舒服。
- 这家餐厅没有我想象中那么贵。
- 我在半导体公司做研发工作。
