# 중국어 누적 문법 노트

> 기존 중국어 공부 대화에서 확인된 표현 중심의 학습용 정리. 전체 대화 원문을 완전히 수집한 자료는 아닙니다.

## 비교
- **A 比 B + 형용사**: A는 B보다 ~하다. 예: 裤子比裙子长20厘米。
- **比想象中便宜**: 생각보다 저렴하다. **比想象中更便宜**도 가능하며 更은 강조.
- **没有想象中那么贵**: 생각만큼 비싸지 않다.
- **更**는 비교 정도를 강조한다. **比较**는 '비교적'의 뜻도 있음.

## 예상과 실제
- **以为**: ~인 줄 알았다. **因为**(~때문에)와 구별.
- **我以为这家餐厅很贵，没想到比想象中便宜，而且菜也很好吃。**
- **想象中**: 상상/생각 속에서. 中은 '속'을 뜻함.

## 연결·강조
- **除了…以外，还…**: ~외에도 …하다.
- **连…都…**: ~조차 …하다. 예: 连运动的时间都没有。
- **不管多…都…**: 아무리 ~해도 …하다.
- **而且**: 게다가(절·서술 연결); **和**: 주로 명사 연결.
- **尤其**: 특히. 예: 我喜欢各种各样的菜，尤其喜欢中国菜。
- **不过**: 하지만.
- **每天都… / 每个周末都…**: 매일 / 주말마다.

## 동사·상태
- **동사 + 过**: 경험. 예: 我以前旅行过很多次。
- **동사 + 起来**: 동작의 시작·방향 외에도 경험적 평가를 나타냄. 예: 穿起来不太舒服 (신어 보니 불편하다), 看起来 (보기에).
- **对…(很)满意**: ~에 만족하다. 예: 我对现在的工作很满意。
- **从事 + 직무**: ~업무에 종사하다. 예: 我在半导体公司从事研发工作。
- **有点儿 / 一点儿**: 약간(주로 상태 평가) / 조금(양·정도).
- **以后 / 再 / 以前**: 이후 / 다시·그다음 / 이전.
- **不会 + 동사**: ~할 줄 모른다 또는 ~하지 않을 것이다(문맥 의존).

## 교통
- **坐地铁上班**: 지하철 타고 출근하다.
- **堵车**: 교통 체증; **路上很多车**는 도로에 차가 많다는 뜻일 뿐 반드시 정체는 아님.
- **迟到了**: 지각했다. **来晚了**: 늦게 왔다.
