# 중국어 공부 누적 데이터

2026-11-03 현재 확인 가능한 중국어 공부 프로젝트 대화·기존 GitHub 기록·일부 수업 자료를 통합했습니다.

- **vocabulary.csv**: 한자·병음·한국어 뜻·분류 (134개; 기존 66개 + 신규 68개)
- **sentences.csv**: 문장·전체 병음·뜻·출처 구분 (25개)
- **grammar.csv**: 문법 패턴·병음·뜻·예문과 예문 병음/해석 (24개)
- **mistakes-detailed.csv**: 원래 답변·교정·병음·뜻·이유·확인 가능한 오답 횟수 (12개)
- **review-history.csv**: 실제 저장된 복습 평가 (1건)
- **anki-review.csv**: 기존 플래시카드 내보내기 자료에 새 단어 후보 추가
- **mistakes.csv**, **grammar.md**, **writing-practice.md**: 기존 파일 보존

## 횟수 해석
- confirmed_error_count는 **확인 가능한 해당 오류 사례의 횟수**입니다. 과거 모든 대화에 대한 완전한 집계가 아닙니다.
- 동일 문장에서 나온 서로 다른 오류는 각각 기록하되, 하나의 오류를 여러 번 발견했다고 중복 가산하지 않습니다.
- 표현 개선만 필요했던 경우는 오답으로 가산하지 않고 0으로 표시합니다.
- 플래시카드의 실제 오답은 review-history.csv에 별도로 기록하며 작문 오류와 혼합하지 않습니다.
- 사용자에게 확인되지 않은 전체 이력은 추정하지 않습니다.

## 범위
이 자료는 **접근 가능한 대화 및 자료 기준 최대한 통합한 버전**이며, 모든 과거 채팅·첨부 이미지의 전체 텍스트를 빠짐없이 확보한 것이라는 의미는 아닙니다. 학습용 보완 예문과 실제 작성 답변은 source_type으로 구별했습니다. 개인정보나 사적인 일기는 포함하지 않았습니다.
